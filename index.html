I2C Address Conflicts

Two I2C devices cannot normally use the same address on the same bus. This checker helps identify overlapping addresses and, when possible, finds an alternative address assignment.

Common examples include MPU6050 and DS3231 at 0x68, or multiple OLED displays using 0x3C. For hardware-specific guidance, verify the exact module datasheet.
